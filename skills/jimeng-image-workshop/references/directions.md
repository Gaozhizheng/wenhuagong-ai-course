# 方向与判定细则（内部文件，不输出给用户）

**查阅方式**：每个任务开头查第一、二节做判定；写词前查第三节方向规矩；成套或需分析的任务查第四节专门设计。
**口径**：方向是初始常用清单，可增删，不必强求归类，够用就行；匹配不到走文末通用兜底，不硬套、不报错。
**铁律**：本文件一切内容（任务码、方向名、判定档位、分析过程）一律不出现在给用户的交付里。
**规则来源**：轮数、闸门、合规、输出格式、延伸，都以 `SKILL.md` 为准，本文件不重复。

## 一、任务入口 T1–T8 判定细则

| 码 | 判定要点 | 最容易混的是 | 怎么分 |
|---|---|---|---|
| T1 从零生成 | 无原图，纯文字生成 | T5 | 有没有给图；给图即不是 T1 |
| T2 图片修复 / 纠错 | 图本身有问题：字错、变形、瑕疵、模糊、多余物体；**修复分保真修复与现代化重制两档**，见 4.6 | T3 | 「修好它」是 T2，「换个样子」是 T3；老照片只说「修复」默认现代化重制 |
| T3 图片改造 | 图没问题，想换背景 / 换装 / 换风格 / 加东西 | T2 | 见上；T2 要「保持其余完全不变」更严格 |
| T4 多图融合 | 两张以上各出一部分，合成一个素材 | T5、T6 的方法图 | 两张以上是 T4；一张是 T5；**方法图 / 规范图 / 教学示意图只作内部参考，不进画面、不算融合** |
| T5 单图参考 | 只借风格 / 构图 / 人物 / 产品特征之一，不重做设计 | T6 | 只借一点是 T5；要分析后重新设计是 T6 |
| T6 分析后创作 | 给一张图，先分析它的设计再产出（电商主图 / 详情页典型） | T5、T3 | T6 先在内部分析，再给用户简短方案，不展示原始分析过程；T3 直接改 |
| T7 系列创作 | 多张要连贯：漫剧、分镜、组图、表情包、**角色三视图 / 设定图** | T1 的一次多张 | 要跨张一致是 T7；只是「出 4 张挑一张」是 T1；设定图专门设计见 4.7 |
| T8 优化与整合已有提示词 | 输入是一段草稿提示词（优化 / 润色 / 诊断 / 改写），**或同一套多段提示词（合并 / 整成一组 / 分版重组）** | 出图后的迭代、从零生成 | 有草稿或是已写好的词是 T8；出图后按效果改走 `SKILL.md` 第八节；只有一句需求没草稿是 T1 |

拿不准才把它变成一个选项问用户，不猜；信息够就按 `SKILL.md` 第二、三节直接出词，**不为走流程而问**。用户一句话里含多个类型（「这张图背景太乱，顺便帮我做张详情页」），取第一个要做的，第二个等用户说「还有呢」再给，不并行跑两套流程。

**例外（不走体检）**：给图但没说改什么（「你看看能怎么改」），直接走 `SKILL.md` 第一节的例外分支列三档改法；用户选定某条后按 T2 或 T3 出词。

## 二、五项体检细则

| 维度 | 够格的样子 | 不够格的样子 | 常见误判 |
|---|---|---|---|
| 任务类型 | 「把这张产品照做成主图」是 T6 | 「帮我弄个图」 | 用户说了一堆形容词，其实没说要生成还是改 |
| 主体 | 「茶叶罐」「本人」「圆脸橘猫」 | 「一个东西」「好看的画面」 | 有形容词不等于有主体；主体缺失时才问，允许用户答「你定」 |
| 用途 | 「详情页首图，给中老年顾客看」 | 「好看点」「高大上」 | 说了风格不等于说了用途 |
| 风格适配 | 儿童活动配明亮绘本、政务配庄重简洁 | 政务配赛博朋克、儿童配暗黑 | 用户给了风格也要判相容性，不能照单全收 |
| 产出形态 | 单张还是成套、要不要字、系列格数明确 | 完全没概念 | 单张或成套会影响流程；比例由智能识别，不强制用户说 |

三档落点：

- **A 清楚且合适**：五项都够格、风格相容 → **直接出词，不追问、不复述确认**。
- **B 有锚点但未落定**：至少一个可靠锚点已知，但关键项缺失或风格不适配；一个选项块收齐当前任务所有缺项。风格与用途打架时，先给一个更合适的建议让用户选，不批评审美。
- **C 暂无可用方向**：任务类型、主体、用途都无法可靠确定；一个选项块收「任务类型、画什么主体、用途」，主体可答「你定」，技能按用途补低风险默认方案。海报的标题原文必须由用户提供（可同一轮收齐），「你定」不授权技能编标题。

**不因用户说得少就把人问烦，也不因第一句话看起来完整就补一轮确认**。同一会话里用户接着给新方向、要下一张、要整套，按连续走查处理，不重开问答。

## 三、方向规矩表（按用途认）

**出图比例双轨**：提示词正文不写比例参数，需要时用「竖幅长图」「横向排布」「方图构图」这类**画面形态**描述；出图指引默认写「以当前界面为准」，但**用途强依赖画幅（手机壁纸、竖版封面、海报、电商主图、PPT 配图、朋友圈长图）或用户已指定比例时，补一句「界面里把比例设为竖版 / 方图 / 横版」**。下表中的形态词是内容描述，不是要用户手动设的参数。

| 方向 | 必含 | 必避 | 默认 | 检查点 |
|---|---|---|---|---|
| 人像写真 / 形象照 | 「保留参考图人物的五官特征和脸型」 | 换脸描述、空形容堆砌、多风格混用、指名真人 | 真实摄影、柔和均匀光、干净背景 | 像不像本人 / 脸手有无畸变 |
| 电商 / 产品图 | 有参考图时「保持产品形状、Logo、标签完全不变」；无图从零生成时把产品外观写清楚，不写「保持」 | 产品变形、改写 Logo、多余文字、背景杂物、无图却写「保持」 | 干净无缝背景、写实、留文字位 | 变形 / 字与 Logo / 光影统一 / 主体突出 |
| 活动海报 / 封面 / 标题字 | 主副文案原文（加双引号）、位置、留字位；原文出词前收齐 | 模型自由发挥文字、字太多、主体压字上、出词时才补要标题 | 字少而大、明确留白 | 字错或乱码 / 字被挡 / 调性 |
| 社媒配图 | 氛围与光线 | 塞满元素、堆画质词、强行加标题 | 生活化真实感、自然光、不加字 | 多余文字 / 过满 / 氛围 |
| 课件配图 / 教学插画 / 信息图 | 「一张用于说明 X 的…」 | 复杂背景、装饰元素、自动生成大段文字 | 扁平插画、留白充足 | 一眼看懂 / 元素关系 / 乱码 |
| 表情包 / 贴纸 / IP | 「同一个…」「一套 X 张」「风格统一」 | 每张单独写导致漂移、一格多动作、指名现有角色 | 统一风格、纯色或透明底 | 角色一致 / 风格统一 / 格子数 |
| 改图 / 修图 / 局部重绘 | 「保持……不变」 | 不写保留项、一次改三处以上 | 保持原图构图、只动指定区域 | 未改处有没有被动 / 接缝 |
| 老照片修复（两档，见 4.6） | 保真档「保持黑白单色影调与年代质感」；重制档「保持五官发型衣着不变＋现代彩色真实摄影质感」 | 借修复之名换脸、擅自上色或擅自保黑白、过度磨皮 | 只说「修复」默认现代化重制 | 还像不像本人 / 划痕网点污渍去净没 / 有无假色块或塑料脸 |
| 角色设定图 / 三视图（见 4.7） | 角色卡（外貌发型发饰服装固定描述）、各格角度与位置、等高同基线、跨格一致 | 每格重写角色、侧背面画成正面、发饰与披帛串样、擅自加文字标签 | 干净纯色背景、柔和均匀正面光、弱化透视变形 | 跨格像不像同一个 / 角度对不对 / 发饰纹样有无串样 |
| 多段提示词整合（见 4.8） | 去掉编号与分块标题、串成一段连贯自然句、内容一条不删 | 擅自删内容、把规划比例写成出图设定、分行改变句子 | 分行只是排版 | 六个版块齐不齐 / 顺序有没有串 / 内容有无遗漏 |
| 融图 / 合成 | 逐图职责、光影统一 | 不指明哪张给什么、光线打架、透视不符 | 统一光线方向与色温、主体不形变 | 变形 / 光影色温 / 悬浮感 |
| 分镜 / 连续画面 | 「一组 X 张」「同一角色或场景」、逐格一个动作 | 一格多动作、跨格漂移 | 各张版式一致、画面清楚、动作简单、风格统一 | 跨格一致 / 每格动作单一 / 顺序 |
| 漫剧 / 连续叙事（T7 专门） | 角色卡（外貌、发型、服装固定描述）、每格复用、画风统一 | 每格重写角色、画风漂移、一格多事件 | 各张版式一致、每格一件事、对白留白 | 角色像不像同一个 / 画风统一 / 叙事顺序 |
| 透明素材 / 抠图产物 | 独立主体、居中、纯色或透明底、无阴影无文字、边缘干净 | 复杂场景、投影、自带文字、同框其他物 | 纯色或透明底 | 边缘残留 / 多余阴影字 / 换背景白边 |

匹配不到走通用兜底；方向间规则可借用，但不并行跑两个方向；风格不算方向，是横切参数。

## 四、需要专门设计的方向

读图六项是通用方法，不限于电商：T2、T3、T4、T5、T6 等所有有图任务，第 0 轮都按六项在内部过一遍；T6 用得最全，其余只取相关项。下面以电商为例，给出「看到什么、词里怎么写」的对应关系。

### 4.1 电商（T6）：先分析，再谈出图

第 0 轮内部做读图分析，六项收敛，每项直接对应提示词该怎么写：

| 看什么 | 判断什么 | 落到词里 |
|---|---|---|
| 主体 | 品类、形状、材质、颜色、Logo / 标签位置 | 「保持…形状、标签文字与位置完全不变」 |
| 构图 | 主体位置、留白够不够、要不要留字位 | 「居中略偏左，右侧留出文字区」 |
| 背景 | 干不干净、有没有杂物、要不要换 | 「换成浅米色无缝背景」 |
| 光线 | 方向、软硬、阴影、与场景是否一致 | 「左侧柔和窗光，弱化硬阴影」 |
| 文字 | 有没有、写什么、放哪 | 「右上角写上 "明前龙井"」 |
| 卖点表达 | 这个产品要传达什么（新鲜 / 手工 / 科技） | 「加几片舒展茶叶与淡淡热气」 |

详情页逻辑，不是一张图，是一套：主图、卖点图、细节特写、参数 / 尺寸、场景图、信任背书。
**用户明说要一套 / 整套 / 一次给齐时，按确认的范围一次给齐**，每段词自包含；否则给短清单让用户勾，只出当前这一张。文案密度按用途走：练习或演示场景下每屏给主标＋副标＋几条说明小字，不要只给一两句。
何时检索见 `SKILL.md` 第五节；平台上架尺寸只作版式规划参考，不写出图指引。

### 4.2 漫剧（T7）：先定角色卡，再排分镜

1. 第 1 轮收：有没有角色参考图、画风、这一页讲什么、几格；缺省项可由用户答「你定」交给技能设定。信息已够则跳过。
2. 先写一段固定的角色卡（外貌、发型、服装、显著特征），每一格提示词都原样复用这一段，只换动作与场景，这是跨格一致的关键。
3. 每格只写一件事、一个动作，遵守课件「画面清楚、动作简单、风格统一」。
4. 用户明说要几格或要整套时给短方案，确认后按格出词；一次给齐即可。
5. 用户指名现有动画角色时，按 `SKILL.md` 第四节改写成画面特征。

### 4.3 海报：信息层级加调性适配

1. 标题和副标原文必须用户给，不许编；练习场景下按 `SKILL.md` 第四节文案边界拟稿，并标明是练习拟稿。其余信息按层级排：主标题、副标、时间地点、主办 / 落款。
2. 提示词里写明留字位在哪，别让主体压在字上。
3. 调性适配检查在这里最容易触发：用途（政务、亲子、促销、公益）与用户给的风格不相容时，给一个更合适的建议让用户选。
4. 单张海报信息够就直接出词；用户要多版式时给「横 / 竖 / 方」的短清单让用户勾，**并在指引里点明界面里把比例设成对应版式**。
5. 海报、封面、手机壁纸这类强画幅用途，**指引里必须带一句比例提示**，否则容易被默认出成方图；提示词正文仍只写「竖幅构图」这类形态词。

### 4.4 融图（T4）：先分配职责，再定合成顺序

1. **收信息**：每张图分别给什么（主体图、场景图、风格图）、哪些细节必须保留、光影以哪张为准。图片数量缺失时，直接说缺几张，不猜；信息够就不发问。
2. **方案（只给套图，单张不占轮）**：**单张融图（两张合一张成品）零轮，直接出词**；只有多场景融图套图、或用户主动要「先给方案」时才给分步顺序，先融主体与场景、再单独调色调，不一次写长句；参考 `examples.md` 融图五法。
3. **出词**：逐图分配职责，写「图1给……，图2给……，光影统一为……」；保留项写成「保持……不变」。
4. 融图里出现真人时，按 `SKILL.md` 第四节人像条款处理。
5. **方法图 / 规范图 / 教学示意图不算待融合的图**：只作内部知识输入，用来理解该怎么做，不进画面、不写进提示词。例如「这张是产品精修方法图，这张是产品图」＝按方法处理产品图，不是两张图合成。
6. 融图套图（同一主体放进多个场景）按成套任务处理，用户要整套就一次给齐。

### 4.5 优化已有提示词（T8 / 9.1）：诊断清单

草稿拿到手，逐项对照，只改命中的项，不全篇重写：

| 检查项 | 问题样子 | 怎么改 |
|---|---|---|
| 主体是否具体 | 「一个好看的画面」 | 补成具体主体与关键外观 |
| 用途是否明确 | 看不出用在哪 | 缺则问一次，用途影响构图与留字位 |
| 是否标签串 / 逗号词堆 | 「高清，唯美，大师作品，8K」 | 合并成一段连贯中文自然句，删画质词堆（输出时按语义分短行，分行只是排版、不拆句） |
| 是否有别的模型语法 | `--ar`、`(词:1.2)`、英文负向词串 | 全部剔除，转成即梦可用的中文表达 |
| 文字是否加引号与位置 | 标题散在句子里 | 加双引号并写清位置 |
| 改图是否有保留项 | 只写「换个背景」 | 补「保持……不变」 |
| 风格与用途是否相容 | 政务海报配暗黑风 | 给适配建议，由用户选，不擅自改 |
| 界面参数 / 动作是否写进词 | 词里写「1:1」「点局部重绘」 | 参数直接删掉、比例交给智能识别；界面动作只留在交付指引里 |
| 是否一格多事（系列） | 一张里塞多个动作 | 拆成每格一件事 |
| 是否含未核实事实 | 编造的产品参数、功效 | 删除或转为向用户索取 |

### 4.6 老照片修复（T2）：先定是哪一档

「修复」有两个方向，别默认替用户选错：

| 档 | 用户说法 | 词里怎么写 | 检查点 |
|---|---|---|---|
| 保真修复（修旧如旧） | 「保留老照片的样子」「别上色」「修旧如旧」 | 保持黑白单色影调与年代质感，只去划痕、网点、噪点、污渍，提清晰度与明暗层次，不过度磨皮、不上色 | 年代感还在不在 / 有没有被上色 |
| 现代化重制（**默认**） | 「老照片修复」「修复一下」「改成现在拍的照片」 | 保持五官、脸型、发型、笑容、衣着、构图完全不变，改成现代数码摄影的真实彩色人像，补自然肤色发色、真实皮肤纹理、柔和光线、高清通透 | 还像不像本人 / 有无假色块或塑料脸 |

- 用户只说「修复」且没指定保真时，**按现代化重制出词**，并在交付里点一句口径、给一句「想要黑白版回一句就换」的说法（这是轻量微调，不是延伸清单）。
- 两档共同的铁律：**保持五官特征与脸型完全不变**，不借修复之名换脸、不美化成网红脸。
- **如实说明边界**：黑白原图没有颜色信息，肤色、发色、衣色是按明暗推断的自然配色，不冒充原照记录的真实颜色；用户给了具体颜色就锁进词里。
- **切档触发词（双向对齐，听到就切，不再追问）**：
  - 切**保真档**：「换黑白版」「要黑白的」「别上色」「修旧如旧」「保留年代感」。
  - 切**现代化重制档**：「要彩色的」「不要黑白的」「改成现在拍的照片」「上色」。
  - 只说档名不说做法时，按对应档直接出词；换档不新增轮次，也不重复问「你确定吗」。

### 4.7 角色设定图 / 三视图（T7）

1. **先写角色卡**：外貌、脸型、发型发色、发饰、服装款式与配色、纹样，一段固定描述；每一格原样复用，只换角度与景别。
2. **版式由用户定**：用户说了怎么排就照排（如「左侧正面特写，右侧正 / 侧 / 背三视图」），没说就按常规横向并排。写清每格的角度、位置、景别。
3. **三视图专门规矩**：全身三格等高、站在同一条水平基线上、姿态一致（如双臂自然张开）、正侧面与背面能看清发饰与服装结构、统一柔和正面光、弱化透视变形、干净纯色背景、格间留均匀空隙。
4. **不主动加「正面 / 侧面 / 背面」文字标签**（中文易错字）；用户要标签就让他给原文，原样排进去。
5. **如实提醒**：侧、背两格最容易把发饰或披帛画成正面；要每格精确可拆成三次单独出图再拼。这属一句轻量微调，不铺开成延伸清单。

### 4.8 多段提示词整合与分版（T8 / 9.2）

- **合并成一段**：按原顺序串成一段连贯中文自然句，去掉编号、分块标题、重复的保留项，**内容一条不删**；分行只影响显示。示范见 `examples.md` 第九节。
- **整成一组 / 分版**：给一条能一次出整张长图的词，各版块自上而下排、版块间用细线与留白分隔，共用同一套保留项、配色与光线方向。
- **比例表只作版式规划参考**：用户要「大概比例」就给一张版块尺寸表，标明用于排版规划、不用于出图设定；出图比例按 `SKILL.md` 的双轨规则处理。别把 750px 宽、1:2、1:6 这类平台规格写成用户必须照做的设定。
- **如实提醒**：一次出整条长图文字容易糊或串位，要每屏字字清楚就逐段出图再拼。
- 这不是迭代，不给「改了哪」。

### 4.9 画面文字写法（即梦中文渲染）

中文文字是即梦最容易翻车的地方，写词时按下面五条收敛：

| 要点 | 怎么写 | 为什么 |
|---|---|---|
| 字数 | 单处 **2–8 字**，主标不超过 12 字 | 字越多越容易糊、缺笔画、串行 |
| 层级 | 明确「主标大、副标中、说明小字最小」，各占一处 | 不分层时模型把三段字挤成一行 |
| 字体形态 | 写「黑体 / 宋体 / 手写 / 书法 / 圆体 / 无衬线粗体」 | 只写「好看的字」等于没指定 |
| 位置 | 逐处给方位（左上、居中、底部、留白区） | 只说「写上」会被随机摆放 |
| 多处防粘连 | 超过三处时写明「各段分开、互不粘连、间距清晰」 | 多段字最常糊成一块 |

避坑：

- 不写生僻字、多音字、繁体混排、超长句；标语超过 12 字就拆成两行或改成副标。
- 标题原文由用户给，**原样照抄**，不顺手改错别字（改了就不是他要的字）。
- 参数、资质、价格这类小字，宁可留空白字位，也不让模型自由生成数字。
- 字多的版式（详情页、长图）如实提醒一句：一次出整条容易糊字，要每屏清楚就逐段出图再拼。

## 五、各方向延伸清单

**默认不主动铺开**：交付里只带一句轻量微调提示。用户说「还有呢 / 换个版本 / 再做一张」时，才给 1–2 条能直接用的：

- 电商：白底图、场景图、带促销字版、细节特写、无字版。
- 海报：横竖方三版、无字底图、九宫格、换主题。
- 漫剧：下一页、三视图、封面。
- 人像：横版、去背景。
- 融图：换场景、换时段。
- 分镜：每格放大、交接视频。
- 透明素材：换角度、二次使用。
- 老照片：保真黑白版 / 自然上色版、更明显的旧照颗粒感。
- 角色设定图：加角度标签、换成半身、加透明底。

用户说「都要」时才按条展开，不一次糊一屏。

## 六、通用兜底（匹配不到方向时）

```
[主体]＋[环境或场景]＋[动作或状态]＋[风格]＋[光影色彩]＋[构图或景别]
```

合并成一段中文自然句，按 `SKILL.md` 第七节 B 的分行规则排成短行（分行不改变句子）；文字加双引号；有原图补「保持……不变」；不写比例、画幅、分辨率这类出图参数。不向用户说明「没匹配到方向」。
