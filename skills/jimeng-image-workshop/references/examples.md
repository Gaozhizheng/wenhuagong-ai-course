# 风格、案例与改法速查（内部文件 · 按需查，不外露）

**净化原则**：以下全部是**即梦能用的中文自然句**。不出现 `--ar`、权重词 `(词:1.2)`、英文负向词串、API / 代码。

## 一、风格速查（换风格只换这一层）

| 维度 | 可选写法 |
|---|---|
| 渲染 / 媒介 | 真实摄影质感、胶片复古、水墨国风、工笔、绘本水彩、3D / C4D 潮玩、CG 电影感、黏土毛毡手作、扁平插画、像素 / 波普 |
| 光线 | 柔和窗光、均匀棚光、清晨薄雾光、黄昏侧逆光、霓虹冷暖对比、顶光硬影 |
| 色彩 | 低饱和莫兰迪、暖黄治愈、冷青科技、高对比撞色、单色系留白 |
| 材质 | 木纹、磨砂玻璃、哑光陶瓷、金属拉丝、纸张肌理、绒毛 |
| 视角 / 景别 | 正面平视、俯拍 45°、微距特写、半身、全身、远景广角 |

**三条铁律**：① 一个主风格，不混两个 ② 抽象词换具象（「高级」→「低饱和、留白多、材质真实」）③ 结构比形容词管用（先定主体与构图，再补风格）。

## 三、改图指令矩阵（「给一张图，咔咔列改法」时用）

**只在 `SKILL.md` 第一节「例外分支」触发时列**（给图却没想好改什么），按「保守 → 中等 → 大改」三档各 1–2 条，每条都写「会改变什么 / 会保留什么」，收尾接一句「选一条我写完整提示词」。此轮**不输出提示词代码块**；用户选定后视为闸门已通过，按 T2 / T3 直接出词，不重走问答、不再确认。

| 组 | 现成指令（挑用） |
|---|---|
| 人物 | 换发型／换服装／换表情／美颜上妆／改年龄感／加配饰／改姿态 |
| 镜头 | 改景别（特写↔全身）／换视角（平视↔俯拍）／改景深／改天气／改时段 |
| 风格材质 | 转国风／转胶片／转插画／转 3D／改色调／改光线方向／改材质 |
| 文字元素 | 改标题内容／换字体风格／去掉文字／加一行小字／修正错字 |
| 场景 | 换背景／去除杂物／加陪体／扩图／局部消除 |

句式统一：`把[对象]改为[特征]，保持[保留项]不变`。
保守档只动一个属性；中等档动一个系统并写明主体特征保留；大改档（风格转绘 / 场景重构 / 融图）提示另存原图再试。

## 四、融图五法（要点）

1. **官方多图融合**：写明「图1给主体、图2给场景」，统一光影方向与色温
2. **产品植入场景**：保留产品细节 → 指定摆放位置 → 补一致方向的自然阴影
3. **风格 / 光影迁移**：只借风格或只借光线，逐图说清职责
4. **分步合成**：先融主体与场景，再单独调色调，别一次写长句
5. **检查重点**：主体有无变形、接触面有无悬浮感、透视与光影是否一致

## 五、翻车 → 定向改法（只改一处）

| 现象 | 改法（可直接复制） |
|---|---|
| 不像本人 | 「加强与参考图人物面部特征的相似度，其余不变」 |
| 产品变形 | 「严格保持参考图产品的形状、比例与标签位置，只改背景」 |
| 文字错 / 乱码 | 「把标题改为 "…"，保持画面其他部分不变」；也可在指引里提示用编辑功能单点修改文字 |
| 风格不统一 | 「把整体风格统一为…，各张保持一致」 |
| 画面太乱 | 「去掉画面中所有次要元素，只保留 X，留出更多空白」 |
| 背景太花 | 「把背景改为纯浅米色，去掉所有其他物体」 |
| 接缝 / 悬浮感 | 「在主体下方加上与场景光线方向一致的自然阴影」 |
| 太亮 / 太暗 | 「把光线调为柔和的上午自然光，降低整体亮度」 |

**规则**：一次只改一处；给改后提示词 + 一句「改了哪」；连改三处仍不行才建议重开一轮。

## 七、在已出图上继续改（保留项加变更项）

用户拿上一张图要再改一处，不重走问答。出词时先复述保留项，再单独写变更项，每条自包含：

```
保持图中人物的五官、发型、服装和姿态不变，
保持整体柔和的暖色调不变，
只把背景从室内书房改成傍晚的海边沙滩。
```

写法要点：保留项放前面、写具体；变更项只写一处；不写「上一张那个」。

## 八、提示词优化对照（T8）

**用户草稿**：

**优化后**：

```

保持罐体形状、标签文字与位置完全不变，
把背景换成浅米色无缝摄影背景，罐子居中，
```
