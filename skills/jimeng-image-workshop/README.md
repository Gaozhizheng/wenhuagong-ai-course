# 即梦图像工坊

`jimeng-image-workshop` ｜ v2.1

## 怎么用

即梦图像工坊 · 使用说明

把想法变成一段能直接复制的即梦提示词。

1. 说一句话：想做什么图，有参考图就一起传；也可以贴一段写好的提示词让我优化。
2. 答选项：我用一两轮问清用途、风格，都给选项，可以答「你定」。传图没想好改什么，就直接给你三档改法挑。
3. 拿去出图：把提示词粘到即梦，有参考图就上传；图片在即梦里生成。出得不对，回一句「太亮了」「字错了」，我只改那一处。

---

> **以上是唯一对外介绍口径**。用户问「怎么用」时只输出这一段普通文本；不分角色、不讲来历、不讲内部规则、不列文件结构、不渲染卡片。以下为内部参考，介绍时不要输出。**规则与判定一律以 `SKILL.md` 为准，本文件只讲用法和走查，不重复规则。**

## 一、三步用法

1. **说一句话**：想做什么图，有参考图就一起传。说得清、说不清都行。
2. **直接拿词或答两句**：信息够就直接出提示词，不为走流程而问；缺用途、风格这类关键项，或必需事实没给时，最多问两轮，每轮一个选项块，可答「你定」，也可自由打字。给图却没想好改什么时不问，直接给三档改法挑。
3. **复制去出图**：新图到图片生成粘贴，改图和融图走图片编辑类功能，以当前界面为准；有参考图就上传。

出得不对，回一句「太亮了」「字错了」「不像」，只改那一处。想在已出的图上继续改，说清要改哪里，要保留的部分会原样写进词里。

已经写好一段提示词？贴过来说「帮我优化一下」，先诊断再给优化版和改动点；只说「只看看别改」，就只给问题清单。有一整套多段词？说「整成一组」「整理成一段」「做个分版设计」，会合并或排成整张长图，并附版块比例作排版参考。

**比例这件事**：提示词里不写比例参数，画面只用「竖幅 / 横向 / 方形构图」描述。出图指引默认「以当前界面为准」；但手机壁纸、竖版封面、海报、电商主图、PPT 配图这类**强依赖画幅**的用途，会额外提醒一句「界面里把比例设成竖版 / 方图 / 横版」，免得被默认出成方图。

## 二、功能一览

| 功能 | 一句话说明 |
|---|---|
| 任务类型判定 | 八类入口，拿不准才变成选项让用户点 |
| 需求判定 | 五项体检、三档走法；清楚且合适就直接出词 |
| 分轮了解 | 默认零轮，该问才问，最多两轮，每轮一个选项块 |
| 模糊词翻译 | 「好看点」「高大上」换成可执行的画面描述 |
| 生图前分析 | 有图任务内部读图六项，电商再加详情页信息层级 |
| 按需检索 | 不认识品类或需要行业惯例时才查，不可用时降级 |
| 专门设计 | 电商、漫剧、海报、融图、老照片两档、角色设定图、多段整合 |
| 按用途出词 | 方向必含与必避，写在内部规矩表里 |
| 画面文字 | 单处 2–8 字、写明字号层级与字体形态、多处防粘连 |
| 看图给改法 | 给图没说改什么，列保守、中等、大改三档 |
| 定点迭代与连续改 | 只改一处；连续走查不重开问答 |
| 提示词优化与整合 | 单段先诊断再优化；多段可合并、整成一组、分版 |
| 成套交付 | 要整套时按张分块给词，文末统一给指引与检查点 |
| 合规与事实边界 | 默认信任本人照片；证件类只说明一次；占位可放行、真实事实不编 |

明确不做：不生成图片、不调 API、不推荐模型、不提版本号、不输出别的模型语法、不替用户判断图能不能用、不做独立成篇的文案文稿。

## 三、十六种运转状态

### A · 说清且合适 → 零轮直出

**用户**：「做一张茶叶电商主图，主体是青瓷茶叶罐，白底，写实，画面简洁不加字。」
**技能**：从零生成加电商，五项够格、风格相容 → 不追问、不复述，直接出词。无参考图，所以不写「保持产品不变」，改为把罐子外观写清楚。

### B · 说不清 → 一个选项块收齐

**用户**：「想做个好看点的图。」
**技能**：一轮选项块：「① 生成新图 / 改一张图 / 几张合成 / 做一套分镜？② 人物 / 食物 / 风景 / 你定？③ 朋友圈 / 电商 / 海报 / 课件 / 你定？」
**用户**：「生成新图，主体你定，朋友圈。」→ 按用途选低风险主体，不编具体个人或品牌；「好看点」翻成干净背景、柔和光、主体突出，出词。

### C · 说了但不合适 → 帮他匹配

**用户**：「做个政务宣传海报，要赛博朋克霓虹风。」
**技能**：风格与用途不相容，且海报标题是必含项，一轮内一并解决：「政务宣传一般要庄重清晰，① 简洁红金 / ② 清爽扁平 / ③ 就按你说的来？另外把标题原文给我，我不替你编字。」
**用户**：「红金，标题写『文明社区 共建共享』。」→ 直接出词。不批评审美，也不照单全收。

### D · 给一张图要改

**用户**：〔传茶叶罐照片〕「背景太乱了，弄干净点。」
**拿到**：

```
把背景换成浅米色无缝摄影背景，
保持茶叶罐的形状、标签文字与位置完全不变，
左侧柔和窗光，弱化硬阴影，其余不变。
```

读不了图时先看环境有没有识图能力；没有就给三句填空：图里主要是什么、想改哪里、哪些别动。

### E · 电商套图：分析设计再出六屏

**用户**：〔传产品实拍〕「想做电商图，卖货用的。」
**技能**：内部读图六项，判断品类、形状、材质、Logo 位置；不认识品类才检索，只补判断。
**第 2 轮**：给详情页清单让用户勾（主图、卖点图、细节特写、参数尺寸、场景图、信任背书），建议先出主图、其余共用同一套光线。
**用户**：「这一套都给我。」→ **按张分块给六段词**，每段自包含，文末统一一句指引与检查点。

### F · 漫剧：先定角色卡

**用户**：「想做一页漫剧，四格，讲姑娘收到一封信。」
**技能**：信息够就直接出词；缺角色参考、画风、格数才问一轮。内部先写固定角色卡（低马尾、圆脸、米白亚麻衬衫、左腕红绳），每格原样复用、只换动作场景，每格一件事。

### G · 出得不对 → 只改一处

**用户**：「右上角那四个字写成乱码了。」
**拿到**：

```
把右上角的文字改为 "明前龙井"，
保持画面其他部分完全不变。
```

改了哪：只换文字内容。也可提示用编辑功能里的文字重绘单点修。

### H · 给图没想好改什么 → 三档改法

| 档 | 例 |
|---|---|
| 保守 | 「把毛衣换成米白色，其余不变」 |
| 中等 | 「背景换成秋日公园，保持五官、发型、服装不变」 |
| 大改 | 「整张转水墨国风插画，姿态与构图保持」，提示先另存原图 |

收尾必接：「选一条告诉我，我把完整提示词写出来。」选定即出词。

### I · 在已出图上继续改

**用户**：「整体挺好，就是背景想换成傍晚的海边。」
**拿到**：

```
保持图中人物的五官、发型、服装和姿态不变，
保持整体柔和的暖色调不变，
只把背景改成傍晚的海边沙滩。
```

先复述保留项，再单写变更项，不写「上一张那个」。

### J · 点名某位画家或角色

**用户**：「画成某某动画里那个角色的样子。」
**技能**：不照搬名字，改写成画面特征，并说明一句「我把名字换成了画面特征，效果更可控」。例：「圆脸、大眼睛、线条干净的日系扁平动漫风，色彩明快。」
若参考图明说是别人或明星要换脸：停下，说明需本人或已授权照片，建议改用本人照片或原创形象。

### K · 带来一段草稿要优化

**用户**：「帮我看看这段：高清唯美茶叶图，大师作品，8K，--ar 1:1，不要杂乱背景，把背景换好看点。」
**技能**：不走问答。诊断：标签串与画质词堆、带 `--ar`、负向表述、改图没写保留项、主体不具体。
**拿到**：优化后一段词 + 三条「改了哪」。只说「只看看别改」就只给问题清单。

### L · 正式证件照：只说明一次

**用户**：〔传写真〕「生成标准证件照。」
**技能**：说明一次——正式证件有官方规格，应按官方要求拍摄；同时给替代（练习用形象照 / 头像）。
**用户**：「练习用的标准形象照。」→ 立刻按替代出词，不重复说明、不二次拒绝。

### M · 老照片：两档别选反

**用户**：〔传褪色黑白旧照〕「对这张照片进行老照片修复。」
**技能**：只说「修复」→ 默认**现代化重制**：保住五官发型衣着构图，改成现代彩色真实摄影，去划痕网点、补自然肤色。
**用户**：「换黑白版。」→ 听到就切**保真档**，保留黑白影调只去瑕疵，不追问、不新开轮。
如实说明：黑白原图没有颜色信息，肤色发色是按明暗推断的，不冒充原照事实。

### N · 角色设定图：版式照用户说的排

**用户**：〔传古风潮玩女孩〕「制作三视图，左侧加一格正面特写，右侧是正 / 侧 / 背。」
**技能**：先写角色卡（双环髻、发冠、发饰、襦裙、披帛），每格原样复用；三格等高、同一基线、姿态一致、统一柔光；默认不加「正面 / 侧面 / 背面」文字标签。侧背两格最容易把发饰画成正面，检查点必查。

### O · 多段词整合与分版

**用户**：「把那六个版块的提示词整成一段」／「整成一组，做个分版设计，列个大概比例」。
**技能**：合并就去编号与分块标题、串成一段，内容一条不删；分版就给一次出整张长图的词，另附版块比例表，**标明只用于排版、不用于出图设定**。提醒一句：一次出整条长图容易糊字，要字字清楚就逐段出图再拼。

### P · 连续走查与方法图

**用户**：同一会话接连给方向（双十一海报 → 书法标题字 → 促销特效字）。
**技能**：按新任务判定但不重开问答，每个方向直接出词，结尾只带一句轻量微调。
**用户**：「这张是方法图，这张是产品图，把产品图精修。」→ 方法图只作内部知识，不进画面、不写进词、不算融合。

## 五、启用与自检

实体在项目 `skills/`，运行位置按所在客户端的技能目录挂载。本机用 Windows Junction 指回实体，命令与登记见 `skills/README.md`。

- 不要在链接路径下改文件，统一改实体，链接自动同步。
- **改动生效分两种**：改了 frontmatter 的 `description`（触发词）要新建会话；只改正文规则，当前会话重新加载技能即可。
- 改动后自检五项：
  1. 版本号**两处**一致：`SKILL.md` 标题与本文开头。
  2. 顶部对外介绍文案在 `SKILL.md` 与本文中逐字一致。
  3. 代码块围栏成偶数，示范按语义分行。
  4. 分享包 ZIP 与 GitHub 仓库同轮更新（见 `skill分享包/README.md`）。
  5. `quick_validate.py` 校验通过。
