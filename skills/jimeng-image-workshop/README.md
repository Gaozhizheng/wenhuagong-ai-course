# 即梦图像工坊

`jimeng-image-workshop` ｜ v2.0

## 怎么用

即梦图像工坊 · 使用说明

把想法变成一段能直接复制的即梦提示词。

1. 说一句话：想做什么图，有参考图就一起传；也可以贴一段写好的提示词让我优化。
2. 答选项：我用一两轮问清用途、风格，都给选项，可以答「你定」。传图没想好改什么，就直接给你三档改法挑。
3. 拿去出图：把提示词粘到即梦，有参考图就上传；图片在即梦里生成。出得不对，回一句「太亮了」「字错了」，我只改那一处。

---

> **以上是唯一对外介绍口径**。用户问「怎么用」时只输出这一段普通文本，不分角色、不讲来历、不讲内部规则、不列文件结构、不渲染卡片。以下均为内部参考，介绍时不要输出。

## 一、核心思路

需求说不清，图就画不好：不知道要说用途，说不出风格，只会讲「好看点」。

三条定盘原则：

1. **判定权在技能**：技能判断用户有没有说清楚、说得合不合适，不凭用户自述。
2. **该问才问，信息够就直接出词**：判定权不丢，但不为走流程而问；只有关键项缺失、风格不适配或必需事实没给时才发问。
3. **说了不等于合适**：用户给了风格，但不适合用途时（政务宣传配赛博朋克），技能温和给建议，让用户选。
4. **先了解完，再设计**：任务、主体、用途、风格适配、产出形态都落定，才写词；落定可以靠内部判定，不必靠问。

设计原则：**内部足够聪明，外部极简**。判定、方向、检索、风格库全部内隐，用户看不到。

## 二、怎么取「中间点」

用户要简单，实现要精准。解法是：**默认零轮直接出词，该问才问；要问就把「多问」压成「点选」。**

| | 默认情况 | 需要发问或给方案时 |
|---|---|---|
| 判据 | 信息够、五项落定、风格相容 | 关键项缺失、风格不适配、必需事实没给、用户明说「做一套 / 出几版 / 先给方案」 |
| 范围 | 单张图、单点改图、单张海报、连续走查里的新方向 | 说不清要做什么、政务配赛博朋克、要整套详情页或几版方案 |
| 轮数 | **0 轮，直接出词** | 1 轮选项块；要方案时再加 1 轮短方案，最多 2 轮 |
| 每轮形态 | 一段词加一句指引 | 一个选项块，或一页短方案让用户勾 |

给图却没说改什么，不占轮，直接列三档改法。同一会话里用户接着给新方向、要下一张、要整套，按连续走查处理，不重开问答、不重新确认已定的做法。用户始终是选择题：点一下、答「你定」、或直接拿词。

## 三、使用方法（三步）

1. **说一句话**：想做什么图，有参考图就一起传。说得清、说不清都行。
2. **信息够就直接拿词**：技能默认直接出提示词，不为走流程而问；只有关键信息缺、风格不合适或必需事实没给时才弹选项，可答「你定」，输入框仍可自由打字。给图却没想好改什么时不问，直接给三档改法让你挑。
3. **复制去出图**：新图到即梦的图片生成粘贴，改图和融图走图片编辑类功能，以当前界面为准；有参考图就上传。比例交给即梦的智能图片比例自动识别，不用手动设定。

出得不对，回一句「太亮了」「字错了」「不像」，技能只改那一处。想在已出的图上继续改，直接说要改哪里，技能会把要保留的部分原样写进去。

已经写好了一段提示词？直接贴过来说「帮我优化一下」，技能会先指出问题，再给优化版和改动点；只想听诊断不想让它改，就说「只看看别改」。写好了一整套多段词？说「整成一组」「整理成一段」「做个分版设计」，技能会合并或排成整张长图，并给版块比例作排版参考。

全程不需要：知道模型版本、会写参数、懂风格术语、填表格、写长描述、手动设画幅。

## 四、核心功能

| 功能 | 一句话说明 |
|---|---|
| 任务类型判定 | 八类入口，拿不准才变成选项让用户点 |
| 需求判定 | 五项体检，三档走法；清楚且合适就直接出词 |
| 分轮了解 | 默认零轮，该问才问，最多两轮，每轮一个选项块 |
| 模糊词翻译 | 「好看点」「高大上」换成可执行的画面描述 |
| 生图前分析 | 有图任务读图六项，电商再加详情页信息层级 |
| 按需检索 | 不认识品类或需要行业惯例时才查，不可用时降级 |
| 专门设计 | 电商、漫剧、海报、融图、老照片两档、角色设定图、多段整合各有独立流程 |
| 按用途出词 | 方向必含与必避，写在内部规矩表里 |
| 看图给改法 | 给图没说改什么，列保守、中等、大改三档 |
| 定点迭代与连续改 | 只改一处；连续走查不重开问答 |
| 提示词优化与整合 | 单段草稿先诊断再优化；多段词可合并、整成一组、分版重组 |
| 比例处理 | 交给智能图片比例自动识别，不写进词、不写进出图指引 |
| 合规与事实边界 | 默认信任本人照片；证件类只说明一次；练习文案可拟，真实参数与品牌事实不编 |

明确不做：不生成图片、不调 API、不推荐模型、不提版本号、不输出别的模型语法、不替用户判断图能不能用、不做独立成篇的文案文稿。

## 五、合规边界

- 默认用的是**自己的照片**，不会每次盘问。
- 如果说明是别人、明星或陌生人的照片，或要求换脸，技能会停下并建议改用本人照片或原创形象。
- 指名某位画家、动画角色或明星时，技能会把名字换成画面特征，效果更可控。
- 只做形象照和头像，不做正式证件照；不生成伪造证件、公章、钞票。用户要正式证件照时**只说明一次**并给替代路径，用户点选替代或说「练习用」就立刻按替代出词，不重复拒绝、不二次盘问。
- **练习拟稿的文案可以拟**（主标、副标、卖点短句），会标明是练习拟稿；**真实事实一律不编**：参数、成分、认证、资质、价格、时间、品牌、极限词。缺了就留空白字位或要原文。画面里要写的字属于本技能，独立成篇的文案文稿不属于。

## 六、用途延伸

默认不主动铺开，交付里只带一句轻量微调提示。用户说「还有呢」「换个版本」「再做一张」时给一到两条，每条都能直接用。用户明说要整套时一次给齐，属于方案本身，不算延伸。

## 七、流程（技能内部，用户无感）

```
判任务类型 →〔例外：给图没说改什么 → 列三档改法 → 选定即出词〕
→〔有草稿 → 诊断 → 优化版加改动点；有多段词 → 合并 / 分版重组〕
→ 五项体检落档 →〔信息够、风格相容 → 直接出词，零轮〕
→〔关键项缺失 / 风格不适配 / 必需事实没给 → 一个选项块〕
→〔用户明说要一套 / 几版 / 先给方案 → 短方案，确认后按范围一次给齐〕
→ 了解完成闸门（未过不给提示词）→ 写一段中文提示词
→ 交付（一段词加一句指引，可再补最多两句）→〔用户回反馈〕只改一处
```

两套输出格式：问答轮、方案轮、列改法轮只给选项块，不给提示词代码块；闸门通过后才切到「一段词加一句指引」。提示词在代码块里按语义分成短行，避免超长单行出现横向滚动条、看不到后半句；换行只影响显示，整段复制粘贴即可。出图比例交给智能图片比例自动识别，不写进词、也不写进出图指引。规则见 `SKILL.md` 第七节 B。

## 八、十六种真实运转状态

### 状态 A · 说清楚且合适，直接出词

**用户**：「做一张茶叶电商主图，主体是青瓷茶叶罐，白底，写实，画面简洁不加字。」（没传参考图）
**技能**：从零生成加电商，五项全够格，风格与用途相容 → **零轮，直接给词**，不追问、不复述确认。
**要点**：判定仍在技能内部完成，只是不必让用户点一次头。无参考图时不写「保持产品不变」，改为把产品外观写清楚，示例词见 `references/examples.md`。

### 状态 B · 说不清楚，一个选项块收齐

**用户**：「想做个好看点的图。」
**技能**：第 1 轮一个选项块：「① 任务：生成新图 / 改一张图 / 几张合成 / 做一套分镜？② 主体：人物 / 食物 / 风景 / 你定？③ 用途：朋友圈 / 电商 / 海报 / 课件 / 你定？」
**用户**：「生成新图，主体你定，朋友圈。」
**技能**：按用途选一个低风险、常见的主体，不添加具体个人、品牌或产品事实；「好看点」内部翻成干净背景、柔和光、主体突出，再出词。比例交给智能图片比例自动识别，指引不写画幅。

### 状态 C · 说了但不合适，帮他匹配用途

**用户**：「做个政务宣传海报，要赛博朋克霓虹风。」
**技能**：风格与用途不相容，海报标题原文是必含项，须在出词前收齐。
**第 1 轮**：「政务宣传一般要庄重清晰，霓虹风容易显得不稳。① 简洁红金版式 / ② 清爽扁平插画 / ③ 就按你说的来，选哪个？另外把海报标题原文给我，我不替你编字。」
**用户**：「红金，标题写『文明社区 共建共享』。」
**技能**：五项落定，直接出词。不批评审美，不照单全收，也不留到交付时再要信息。

### 状态 D · 给一张图要改

**用户**：〔传一张家里拍的茶叶罐照片〕「背景太乱了，弄干净点。」
**技能**：图片改造；读图六项只取相关项，只写改背景与保留项。读不了图时，先看有没有 `image-vision-skill` 可用，没有就给三句填空：「图里主要是什么？想改哪里？哪些别动？」
**用户拿到**：

```
把背景换成浅米色无缝摄影背景，
保持茶叶罐的形状、标签文字与位置完全不变，
左侧柔和窗光，弱化硬阴影，其余不变。
```
去即梦的图片编辑类功能粘贴并上传原图。检查：罐子有没有变形、原桌面杂物有没有残留。

### 状态 E · 电商：给一张图，分析设计，详情页套图

**用户**：〔传一张产品实拍〕「想做电商图，卖货用的。」
**技能第 0 轮**：分析后创作；读图六项，判断品类、形状、材质、Logo 位置；不认识品类时检索，只补判断，不写未核实的产品参数。
**第 1 轮**：「这是〔某品类〕，我按电商主图来做。用在哪：详情页首图 / 平台主图 / 朋友圈？图上放不放字，放的话把原文给我？」
**第 2 轮（短方案）**：给详情页逻辑的一页清单让用户勾：`主图、卖点图、细节特写、参数尺寸、场景图、信任背书`，并建议先出主图，其余保持同一套光线与背景。
**用户说**：「这一套都给我。」→ **按范围一次给齐六屏**，每段词自包含，不逐张卡「接着出」。用户只说「先出主图」时才只给当前一张。
**要点**：分析、检索、方案都在内部完成；产品保真、信息层级、跨张一致性一个没丢；练习或演示场景下每屏文案给足主标＋副标＋几条说明，真实参数留空白字位不编。

### 状态 F · 漫剧：先定角色卡，再排分镜

**用户**：「想做一页漫剧，四格，讲姑娘收到一封信。」
**技能**：系列创作；信息已够时直接出词，缺「角色参考图、画风、几格」才发一个选项块；用户明说要几版方案才加一轮短方案。
**内部**：先写一段固定角色卡（低马尾、圆脸、米白亚麻衬衫、左腕红绳），每格提示词原样复用，只换动作与场景；每格只一件事。
**用户拿到**：一段四格分镜提示词，见 `references/examples.md`。

### 状态 G · 出得不对，只改一处

**用户**：「右上角那四个字写成乱码了。」
**技能**：不重走问答，不整段重写：

```
把右上角的文字改为 "明前龙井"，
保持画面其他部分完全不变。
```
改了哪：只换了文字内容。也可以用编辑功能里的文字重绘单点修。

### 状态 H · 给图但没想好改什么，列三档改法

**用户**：〔传一张人像〕「你看看能怎么改？」
**技能**：不进体检，不占轮，直接列三档，每条写清会改变什么、会保留什么：

| 档 | 例 |
|---|---|
| 保守 | 「把毛衣换成米白色，其余不变」，只动颜色 |
| 中等 | 「把背景换成秋日公园，保持人物五官、发型、服装不变」，动一个系统 |
| 大改 | 「整张转为水墨国风插画，人物姿态与构图保持」，提示先另存原图 |

**收尾必接**：「选一条告诉我，我把完整提示词写出来。」用户选定即视为闸门通过，直接出词。

### 状态 I · 在已出图上继续改

**用户**：〔上一张图出来了〕「整体挺好，就是背景想换成傍晚的海边。」
**技能**：不重走问答。复述保留项，再单写变更项：

```
保持图中人物的五官、发型、服装和姿态不变，
保持整体柔和的暖色调不变，
只把背景改成傍晚的海边沙滩。
```
去编辑功能粘贴并上传上一张图。检查：人物有没有被改动、海边光线和人物光线是否一致。

### 状态 J · 点名某位画家或某个角色

**用户**：「画成某某动画里那个角色的样子。」
**技能**：不照搬名字，改写成画面特征，并说一句话：「我把名字换成了画面特征，效果更可控。」
**改写示例**：「圆脸、大眼睛、线条干净的日系扁平动漫风，色彩明快。」
**若用户说参考图是别人或明星的照片，要换脸**：技能停下，说明需要本人或已获授权的照片，建议改用本人照片或原创形象。

### 状态 K · 带来一段写好的提示词要优化

**用户**：「帮我看看这段：高清唯美茶叶图，大师作品，8K，--ar 1:1，不要杂乱背景，把背景换好看点。」
**技能**：判定为优化任务，不走问答。内部诊断：标签串和画质词堆、带 `--ar`、用了负向表述、改图没写保留项、主体不具体。
**用户拿到**：优化后的一段提示词，加三条「改了哪」——删画质词堆和 `--ar`、补上主体和保留项、把「不要杂乱」换成具体的干净背景。
**若用户只说「只看看别改」**：只给问题清单和改法建议，不给成品词。
**要点**：优化保住原意，不替换用户选定的主体和风格；评价的是提示词，不是图片。

### 状态 L · 正式证件照：只说明一次就放行

**用户**：〔传一张带妆写真〕「生成标准证件照。」
**技能**：只说明一次——正式证件有官方规格要求，应按官方要求拍摄或采集；同时给替代路径（练习用的形象照／头像）。
**用户**：「练习用的标准形象照。」→ **立刻按替代出词**，不重复说明、不二次拒绝、不再弹一轮选项。
**要点**：合规提示只讲一次；用户点选过的替代项要认，不把已经答过的再问一遍。

### 状态 M · 老照片修复：两档别选反

**用户**：〔传一张褪色黑白旧照〕「对这张照片进行老照片修复。」
**技能**：只说「修复」且没指定保真 → 默认**现代化重制**：保住五官、脸型、发型、衣着、构图，改成现代数码摄影的真实彩色人像，去划痕网点、补自然肤色、真实皮肤纹理。
**用户**：「不是要黑白老照片，是改成现代摄影技术拍下来的真实照片。」→ 与默认一致，按同一轮修正直接出词。
**如实说明**：黑白原图没有颜色信息，肤色发色衣色是按明暗推断的自然配色，不冒充原照事实。
**若用户说「保留黑白 / 修旧如旧」**：切到保真档，去瑕疵提清晰但保留黑白影调与年代感。示范见 `references/examples.md` 第九节。

### 状态 N · 角色设定图：用户自定义版式

**用户**：〔传古风潮玩女孩〕「制作三视图，左侧加一格人物正面特写，右侧是传统的正 / 侧 / 背。」
**技能**：系列创作；版式照用户说的排，先写死角色卡（双环髻、发冠、发饰、襦裙、披帛），每格原样复用；三格等高、同一水平基线、姿态一致、统一柔光。默认不加「正面／侧面／背面」文字标签。
**要点**：侧、背两格最容易把发饰或披帛画成正面，检查点必查；示范见 `references/examples.md` 第九节。

### 状态 O · 多段提示词整合与分版

**用户**：「把那六个版块的提示词整成一段」／「整成一组，做个分版设计，列个大概比例」。
**技能**：整合任务，不走体检、不重开问答。合并就去掉编号与分块标题、串成一段连贯自然句，内容一条不删；分版就给一次出整张长图的词，另附版块比例表，**标明只用于排版规划、不用于出图设定**。
**如实提醒**：一次出整条长图文字容易糊或串位，要每屏字字清楚就逐段出图再拼。

### 状态 P · 连续走查与「方法图＋对象图」

**用户**：同一个会话里接连给方向名（双十一海报 → 书法标题字 → 促销特效字 → 氛围标题字）。
**技能**：按新任务判定，但**不重开问答、不重新确认已定做法**（练习拟稿口径、比例交给智能识别、检查点写法沿用），每个方向直接出词；结尾只带一句轻量微调提示，不铺开延伸清单。
**用户**：「这张是产品精修方法图，这张是产品图，把产品图商业级精修。」
**技能**：方法图只作内部知识输入，用来理解该怎么做，**不进画面、不写进提示词、不算融合**；处理对象始终是那张产品图。

## 十、启用方式

按项目约定，实体在 `skills/`，在 `.workbuddy/skills/` 建 Windows Junction 指回实体。已接通，命令与规范见 `skills/README.md`。
